# Aikas Candy Mountain

Eine kleine Web-App: Ein Candy-Berg, der sich durch Bewegung und Müllsammeln füllt und wieder leeren lässt. Zwei Katzen begleiten das Füllen und das Leeren.

## Nutzen

- **Online:** https://catfatherindi.github.io/aikas-candy-mountain/
- **Auf dem Handy:** Link öffnen und auf den Startbildschirm legen. iPhone: Teilen → "Zum Home-Bildschirm". Android (Chrome): Menü → "Zum Startbildschirm".
- **Offline:** Datei `index.html` herunterladen und im Browser öffnen.

Der Füllstand bleibt im jeweiligen Browser gespeichert.

## Updates

Oben rechts sucht der runde Knopf nach einer neuen Version. Ist eine verfügbar, erscheint die Frage "Update laden?". Bei "Ja" lädt sich die App neu, der Füllstand bleibt erhalten.

## So funktioniert es

- Der Berg fasst maximal **1.000 CME** (Candy-Mountain-Einheiten).
- **Füllen** (unten links): das ganze Jahr möglich. Ein Fenster öffnet sich, in dem Mengen eingetragen werden. Die App rechnet in CME um.
- **Leeren** (unten rechts): Ein Ablauf aus mehreren Fenstern führt zur Auswahl von Candy oder Cake. Danach wird der Berg geleert.
- Bei jedem Öffnen startet die App mit einer Anfangs-Szene.

## Belohnungen

Am Anfang ist nur Müllsammeln freigeschaltet. Jede Freischaltung zeigt nach dem Füllen eine Szene:

| Eingabe in einem Füllen | Szene und Belohnung |
| --- | --- |
| Müllsammeln ab 200 g | Katzen auf Fahrrädern. Radfahren wird freigeschaltet. |
| Radfahren ab 10.000 m | Katzen auf Stand-up-Paddeln. Stand-up-Paddeln wird freigeschaltet. |
| Stand-up-Paddeln ab 5.000 m | Katzen mit Laufschuhen. Laufen wird freigeschaltet. |
| Laufen ab 5.000 m | Katzen an der Boulderwand. Klettern wird freigeschaltet. |
| Klettern: mindestens 1 Route Grad 5 | Katzen im Zug, Aika bekommt eine Krone, +100 CME. |
| Radfahren nochmals ab 5.000 m | Tiramisu und Risotto. Am selben Tag kostet Naschen 0 CME. |

Die Freischaltungen bleiben erhalten, auch nach dem Leeren.

## Umrechnung in CME am Fülltag (20.10.)

| Aktivität | CME |
| --- | --- |
| Müllsammeln | 1 g = 1 CME |
| Laufen | 100 m = 1 CME |
| Radfahren | 500 m = 1 CME |
| Klettern Grad 4 | 1 CME je Route |
| Klettern Grad 5 | 2 CME je Route |
| Klettern Grad 6 | 4 CME je Route |
| Stand-up-Paddeln | 300 m = 1 CME |
